# Winzo V3.2 rebuild

## Connection and deployment
- Unified player/admin WebSocket endpoint to `wss://winzo-authoritative-server.onrender.com`.
- Removed stale SQLite deployment references; the live server architecture is Firebase Realtime Database.
- Render Blueprint keeps the `0.5c-512mb` Web Service plan and uses Render `PORT`.
- Added WebSocket origin allow-list via `ALLOWED_ORIGINS`.
- Added real Firebase-backed `/health` probing with HTTP 503 when the database is unavailable.

## Authentication
- Production player authentication requires Telegram Mini App `initData`.
- Numeric Telegram user IDs are bound to Winzo accounts; usernames are not the permanent identity.
- Accounts with no Telegram username can still authenticate using a `tg_<telegram-id>` account key.
- Added WebSocket authentication timeout and explicit close codes for failed authentication.
- Development username authentication remains available only with `NODE_ENV=development` and `DEV_ALLOW_ANY=true`.

## Game/economy
- Bots are visual participants only and no longer inflate the real prize pool.
- Bots cannot receive real payouts or determine the winning number.
- Room persistence is performed inside the room mutex to reduce stale-state overwrites.
- Added graceful SIGTERM/SIGINT shutdown persistence.

## Transactions
- Transaction IDs are generated by the server instead of trusting client IDs.
- Added a safe client-request-ID mapping so deposit screenshots still attach to the authoritative server transaction ID.
- Fixed pending transaction timestamp sorting.
- Withdrawal reservation is rolled back if transaction creation fails.
- Notification reads are restricted to notifications belonging to the authenticated user.

## Security
- Removed real credentials from `.env.example`.
- Added constant-time admin-key comparison.
- Existing credentials previously committed to the original project must be rotated outside this package.

## Validation
- `server.js` passes Node syntax validation.
- The final inline JavaScript from `index.html` passes Node syntax validation.
